# PeerTube UI Inventory

This file tracks PeerTube-visible UI down to controls/buttons and maps it to Vidra implementation and tests.

Status values: `NOT_STARTED`, `SURVEYED`, `IMPLEMENTED`, `TESTED`, `VERIFIED`, `INTENTIONAL_DIFFERENCE`, `DEFERRED`, `BLOCKED`.

> **Reconciliation legend (2026-07-03 close-out).** `VERIFIED` = a data-mutating control
> proven end-to-end against a real vidra-core + PostgreSQL by an `e2e-backed/*` spec that is
> part of the standard backed run (**74 passed / 0 failed**). `TESTED` = a frontend-only /
> read-only / presentational control with mocked Playwright + unit coverage but no DB effect
> to prove (its terminal honest status). `IMPLEMENTED` = shipped app-shell chrome with
> Playwright coverage. `INTENTIONAL_DIFFERENCE` / `DEFERRED` / `BLOCKED` name a divergence or
> a pending backend dependency. Controls whose backed spec is one of the five **env-gated**
> specs (atproto / whisper / peertube-import / registration-approval / quarantine) stay
> `TESTED`/`FRONTEND_PARTIAL` until their special stack runs. The seed `NOT_STARTED` rows were
> reconciled to real statuses in this close-out; the only `NOT_STARTED` text that remains is
> the illustrative template block below.
